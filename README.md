## ระบบแบบเรียนฝึกสนุกเกอร์พื้นฐานด้วยเทคนิค Computer Vision และการให้ข้อมูลป้อนกลับแบบทันที

**A Modular E-Learning System for Fundamental Snooker Training Using Computer Vision and Real-Time Feedback**

โครงงานนี้มุ่งพัฒนาระบบสำหรับฝึกสนุกเกอร์พื้นฐานด้วยตนเอง โดยประยุกต์ใช้คอมพิวเตอร์วิทัศน์เพื่อวิเคราะห์ท่าทาง การส่งคิว และการเคลื่อนที่ของลูก พร้อมแสดงข้อมูลป้อนกลับและบันทึกประวัติให้ผู้ฝึกสามารถทบทวนและเปรียบเทียบความสม่ำเสมอระหว่างรอบการฝึกได้

## บทเรียนหลัก

| บทเรียน | ขอบเขต |
|---|---|
| **1. การจัดระเบียบร่างกาย** | ตรวจแนวท่อนแขนและเข่าฝั่งแทง รอเตรียม 5 วินาที บันทึก 8 วินาที |
| **2. การส่งคิวพื้นฐาน** | แดงสองแถวข้างละ 3 ลูก น้ำเงินผ่านช่องกลาง และหัวคิวประมาณถึงแนวคู่ที่ 3 ประเมินครั้งเดียว |
| **3. แบบฝึกลูกพื้นฐาน** | เหลี่ยมเต็มใบ, 3/4 ลูก, 1/2 ลูก และ 1/4 ลูก โดยประเมินการกระทบตามเหลี่ยม ไม่พิจารณาการลงหลุม |
| **4. การแก้สนุกพื้นฐาน** | หน้าตัวอย่างแบบฝึกหนึ่งชิ่ง 3 รูปแบบ ยังไม่เปิดฝึกหรือบันทึกผล |

ปัจจุบัน: M1 ตรวจท่อนแขนเอียงจากแนวดิ่งไม่เกิน 15° ข้อมือต่ำกว่าศอก และเข่าฝั่งแทง 160–180° ต้องวัดพร้อมกันได้อย่างน้อย 80% และถูกพร้อมกันอย่างน้อย 80% ของเฟรมที่วัดได้หลังฐาน 1 วินาที ก้มอย่างน้อย 30° ก่อนเริ่มเท่านั้น เตรียมตัว 5 วินาที บันทึก 8 วินาที โดยใช้เกณฑ์นำร่องที่ผู้จัดทำกำหนด ส่วน M2–M3 ใช้การตั้งค่าเฉพาะโมดูล

## แนวทางการทำงาน

ใช้กล้องด้านข้างสำหรับ M1 และกล้องบนสำหรับ M2–M3 ทีละโมดูล จากนั้นคำนวณตัวชี้วัด ประเมินผล และส่งข้อมูลไปยังหน้าเว็บ พร้อมจัดเก็บประวัติในฐานข้อมูล

```text
เลือกแบบฝึก → ตรวจความพร้อม → รับภาพและวิเคราะห์ → ประเมินผล → แสดงข้อมูลป้อนกลับ → บันทึกและทบทวนผล
```

## เทคโนโลยี

- **Python, MediaPipe Full และ OpenCV/HSV:** ประมวลผลภาพ วิเคราะห์ท่าทาง และตรวจจับลูก
- **FastAPI:** จัดการ API และข้อมูลการฝึก
- **React และ WebSocket:** แสดงหน้าเว็บและข้อมูลป้อนกลับระหว่างฝึก
- **PostgreSQL:** จัดเก็บข้อมูลแบบฝึก เกณฑ์ประเมิน รอบฝึก และผลการวัด
