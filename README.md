## ระบบแบบเรียนฝึกสนุกเกอร์พื้นฐานด้วยเทคนิค Computer Vision และการให้ข้อมูลป้อนกลับแบบทันที

**A Modular E-Learning System for Fundamental Snooker Training Using Computer Vision and Real-Time Feedback**

โครงงานนี้มุ่งพัฒนาระบบสำหรับฝึกสนุกเกอร์พื้นฐานด้วยตนเอง โดยประยุกต์ใช้คอมพิวเตอร์วิทัศน์เพื่อวิเคราะห์ท่าทาง การส่งคิว และการเคลื่อนที่ของลูก พร้อมแสดงข้อมูลป้อนกลับและบันทึกประวัติให้ผู้ฝึกสามารถทบทวนและเปรียบเทียบความสม่ำเสมอระหว่างรอบการฝึกได้

## บทเรียนหลัก

| บทเรียน | ขอบเขต |
|---|---|
| **1. การจัดระเบียบร่างกาย** | การยืน มุมข้อศอก แนวลำตัวและแผ่นหลัง และความนิ่งของศีรษะ |
| **2. การส่งคิวพื้นฐาน** | ความตรงของการส่งคิว ความมั่นคงของสะพานมือ ความนิ่งของศีรษะ การแทงบริเวณกึ่งกลางลูกขาว และการส่งคิวทะลุลูก |
| **3. แบบฝึกลูกพื้นฐาน** | เหลี่ยมเต็มใบ, 3/4 ลูก, 1/2 ลูก และ 1/4 ลูก โดยประเมินการกระทบตามเหลี่ยม ไม่พิจารณาการลงหลุม |
| **4. การแก้สนุกพื้นฐาน** | การแก้สนุกหนึ่งชิ่งในรูปแบบคงที่ 3 รูปแบบ |

## แนวทางการทำงาน

ระบบออกแบบให้ใช้กล้องเว็บแคม 2 ตัว โดยกล้องด้านข้างวิเคราะห์ท่าทางและการส่งคิว ส่วนกล้องด้านบนตรวจจับและติดตามลูก จากนั้นคำนวณตัวชี้วัด ประเมินผล และส่งข้อมูลไปยังหน้าเว็บ พร้อมจัดเก็บประวัติในฐานข้อมูล

```text
เลือกแบบฝึก → ตรวจความพร้อม → รับภาพและวิเคราะห์ → ประเมินผล → แสดงข้อมูลป้อนกลับ → บันทึกและทบทวนผล
```

## เทคโนโลยี

- **Python, MediaPipe, OpenCV และ YOLOv8:** ประมวลผลภาพ วิเคราะห์ท่าทาง และตรวจจับลูก
- **FastAPI:** จัดการ API และข้อมูลการฝึก
- **React และ WebSocket:** แสดงหน้าเว็บและข้อมูลป้อนกลับระหว่างฝึก
- **PostgreSQL:** จัดเก็บข้อมูลแบบฝึก เกณฑ์ประเมิน รอบฝึก และผลการวัด
